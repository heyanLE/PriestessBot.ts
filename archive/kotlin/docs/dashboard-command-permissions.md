# Dashboard 命令权限说明

命令范围按运行态固定。发送者授权页只分配运行态；Agent 页只选择工具、资源、执行环境和审批规则。

## 页面入口

- Agent → 执行与审批 → 查看可用命令与参数。
- 工具与插件 → 能力目录 → 查看命令执行范围与参数。
- 发送者授权 → 查看三个运行态的固定权限。

命令名称、用途、语法和角色范围来自 [command-policy.ts](../typescript/packages/contracts/src/command-policy.ts)。Dashboard 不维护另一份命令清单。

## 三态的不同含义

| 运行态 | 命令执行方式 | 执行环境 |
| --- | --- | --- |
| 普通干员态 | 受限读取命令。只接受已列出的命令和参数。 | Docker 或 SDK Docker。 |
| 资深干员态 | 包含普通干员命令，增加受限文件整理和下载。 | Docker 或 SDK Docker。下载还需要执行环境允许网络。 |
| 高级资深干员态 | 完整 Shell、脚本、解释器与终端输入。 | 使用所选执行环境；本机环境按服务账户权限运行。 |

`exec_command` 的最低运行态只表示可以调用命令工具，不表示获得完整 Shell。普通和资深干员输入的命令由受限运行器处理，不能通过管道、重定向、命令替换或解释器执行额外程序。

权限契约区分 `process.execute.restricted` 与 `process.execute`。前者用于普通和资深干员的内置白名单执行；后者代表完整执行权限，只给高级资深干员。原生扩展若声明旧的 `process.execute`，仍需高级资深干员，不会因普通干员可以使用受限命令而自动开放。

启动命令需要装配工具，选择执行环境和允许的工作目录。受限命令的源路径和目标路径继续按授权范围检查。完整 Shell 的实际权限由所选环境和服务账户决定。批准工具调用不会增加运行态权限，也不会扩大命令清单。子 Agent 不会获得高于父任务的运行态。

普通和资深干员不能向进程写入任意内容。等待命令完成时使用进程轮询工具；终端输入需要高级资深干员态。

受限下载只接受 HTTP(S) GET，目标必须解析为公网 IPv4，禁止内网和本机地址。执行环境必须开启网络。下载不跟随重定向，不接受上传或自定义请求头。单文件最多 20 MiB，最长等待 30 秒。输出必须是工作目录内的新文件，不能覆盖已有文件。页面数值和开关读取同一契约中的 `restrictedDownloadLimits`。

受限 cp、mv 和 curl 不会覆盖已有文件。写入或下载失败时，可能留下部分文件，系统不会自动删除目标。请检查目标，并选择新路径重试。

## 文案与验证

页面用“受限命令”“完整 Shell”“终端输入”区分三个概念。参数表显示契约中的准确语法，不把未知参数描述为可用。命令参数和执行环境必须由服务端检查，前端帮助不会授予权限。

前端测试覆盖清单与契约一致性、最低态与完整 Shell 的区别、输入权限和容器限制说明。实际命令、参数、路径和下载安全检查由服务端及执行后端测试验证。
