# 按运行态限制执行命令

策略源为 `packages/contracts/src/command-policy.ts`。解析器是 `packages/core/src/command-policy.ts` 的 `compileCommandPolicy(command, state)`。`state` 只能来自可信 `RunContext`，不能接受模型参数中的角色。

| 运行态 | 命令 |
| --- | --- |
| 普通干员态 | `pwd`、`ls`、`cat`、`head`、`tail`、`wc`、`grep`、`find`、`stat`、`du` |
| 资深干员态 | 继承普通命令，增加 `mkdir`、`cp`、`mv`、`touch`、`curl` |
| 高级资深干员态 | 完整 Shell 与终端输入，按执行环境和服务账户权限运行 |

普通与资深命令不是任意系统二进制的白名单。解析器生成按命令区分的结构化操作，由受信任 Node 执行器实现文件及 HTTP 操作。原始命令不会传给 Shell。低态必须使用 Docker 环境；local 执行只供高级资深干员使用。

## 支持的参数

- `ls`：仅 `-a`、`-l`，可写成 `-al`。
- `head`、`tail`：仅 `-n 1..1000`，默认 10 行；不支持 tail 持续跟踪。
- `wc`：最多选择一个 `-l`、`-w` 或 `-c`。
- `grep`：只按固定字符串搜索；支持 `-F`、`-i`、`-n`，不接受正则、递归或文件来源参数。
- `find`：一个相对路径，以及 `-maxdepth 0..10`、`-type f|d`、`-name`。默认深度 3，名称只支持 `*` 和 `?` 通配符。禁止 `-exec`、`-delete` 等其他操作。
- `mkdir`：仅 `-p`；`cp`、`mv`：一个源文件与一个新目标路径，仅普通文件，无递归，不覆盖已有目标；`touch` 无附加参数。
- `curl`：一个 HTTP(S) 地址和显式 `-o` 或 `--output` 文件。只下载公网 IPv4，最多 20 MiB、30 秒，不跟随重定向，不覆盖已有文件。禁止配置文件、请求头、认证、上传等参数。网络与真实路径检查由执行后端再执行。

其余命令不接受额外选项。每次最多 20 个路径、64 个词法参数；受限命令最多 8192 个字符。

复制、移动或下载失败时，执行器不会自动删除用户目标路径。目标路径可能保留部分文件。请先检查文件，再选择新的输出路径重试。

## 拒绝的语法

命令名必须直接写出，不能使用绝对命令路径、`./程序`、环境变量前缀、包装器、解释器、引号拼接或转义名称。参数可以使用引号和普通空格转义。管道、重定向、命令链、命令分组、换行和注释均被拒绝。变量、命令替换和反引号即使写在引号内也被拒绝。

带查询参数的 URL 应加引号，例如 `curl "https://example.com/file?a=1&b=2" -o downloads/file.txt`。引号内的普通标点是数据，不作为 Shell 语法执行。

文件路径必须相对于当前工作目录。禁止 `..`、外部绝对路径、盘符、反斜杠、`~`、路径通配符及标准输入 `-`。真实执行还必须验证路径解析、符号链接、文件类型和工作目录边界；词法检查本身不代替这些检查。

## 权限边界

受限命令使用 `process.execute.restricted`，读写操作还分别要求 `files.read` 或 `files.write`，下载额外要求 `external.write`。完整 Shell 额外要求旧的 `process.execute`。只有高级资深干员拥有 `process.pty`，可发送非空终端输入。

该子集约束内置执行后端，不声称能限制已信任原生扩展或外部 MCP 服务内部的任意代码。声明旧 `process.execute` 的原生操作仍要求高级资深干员。其他扩展操作继续遵守自己的工具契约、固定态要求和信任边界。
