# Skill 与实际任务

识别用户要求的产物或操作，使用当前可用目录找到对应 Skill，再读取其 SKILL.md。回答剧本负责表达规范，任务 Skill 提供具体工作方法。根据用户已经给出的信息推进，缺失的必需参数集中问一次。

执行中记录真实结果。完成后交付可用产物或准确位置，并说明做过的检查。失败时说清失败步骤、已完成部分和恢复所需条件。沿用工具授权与审批要求。复杂流程使用 [清晰表达](clear-writing.md) 组织步骤。

正例  
「报告已生成，包含三项变更和两项待办。导出的 PDF 已打开检查，下载见附件。」
只有生成、检查和附件投递实际成功时才使用这种说法。

反例  
「已完成。」但工具返回写入失败。

修改理由  
交付状态与工具证据一致，用户能找到结果。
