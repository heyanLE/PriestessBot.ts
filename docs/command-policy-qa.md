# 分级命令执行验收（2026-10-29）

## 范围

普通干员使用工作目录内的读取子集；资深干员增加文件整理和有界下载；高级资深干员保留完整 Shell。角色来自服务端运行上下文，模型不能自行指定。

命令表与参数以 `packages/contracts/src/command-policy.ts` 为唯一产品契约。`process.execute.restricted` 与旧 `process.execute` 分离，避免向低态开放声明旧能力的任意代码扩展。

## 验收点

- SDK 入口在执行后端调用前检查命令及所需权限；后端再次检查，批准调用不提升角色。
- 普通/资深原始输入不进入 Shell。命令被解析为结构化操作，并由固定 Node 程序执行；只支持 Linux Docker。
- 文件路径检查包含相对路径、目录描述符定位、禁止跟随符号链接、拒绝硬链接与特殊文件。读写/遍历/输出均有上限。
- 受限下载固定为 GET，检查并固定 DNS 返回的公网 IPv4，保持 TLS 证书校验，不接受自定义认证/上传/代理配置，不重定向。最多 20 MiB、30 秒。
- 复制与下载只创建新目标，失败可能留下部分文件。不会为清理失败结果而自动删除可能被并发替换的目标路径。
- 进程归属包含运行态和授权版本；普通/资深没有非空终端输入权限。
- 此策略约束内置执行工具。可信原生扩展和 MCP 仍受自己的装配、工具契约与权限边界约束。
