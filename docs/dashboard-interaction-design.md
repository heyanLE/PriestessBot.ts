# Dashboard 操作结构与清晰文案

日期：2026-10-28。依据：用户选定的 `prototypes/dashboard-ux` HTML 原型，以及正式服务的现有功能和权限规则。

## 页面层级

一级入口为工作台、Agent、机器人、资源库、设置。原有页面 URL 保留，新增 `/resources` 与 `/tools` 作为聚合入口。

| 入口 | 页面与操作 |
| --- | --- |
| 工作台 | 概览、会话记录、控制台对话、任务与审批、后台进程、文件 |
| Agent | 选择或新增 Agent；人设与模型、能力与资料、上下文与记忆、权限与执行；右侧模型测试 |
| 机器人 | 平台实例及接入向导、消息路由、发送者授权 |
| 资源库 | 人格、知识库、长期记忆、工具目录、插件设置、搜索、MCP、Skills、原生扩展 |
| 设置 | 系统与凭据、模型连接、执行环境 |

原有知识索引、记忆整理、插件订阅、人格示例、会话分组、工作目录和运行审批操作继续使用真实接口。没有用原型数据替代正式功能。

## 保存与测试

单个 Agent 与人格绑定在同一数据库事务中校验修订并保存。服务端只将该 Agent 合入已发布配置。前端保留其他 Agent、资源及页面的草稿，包括尚未填写完整的字段。

单 Agent 保存仍会调用现有运行配置应用流程。确认框显示当前活动任务数量、真实修改分组和中断影响，不能用“只保存当前 Agent”暗示其他运行任务不受影响。全局配置发布使用同一影响确认。

草稿测试调用真正的 Agents SDK 引擎，使用临时内存会话。测试不创建正式会话，不提供工具，不使用生产记忆，也不发送 IM。每次请求独立；支持取消、超时与用量查看。测试输入只在完成后清空，失败和取消时保留。隔离验收环境使用本地脚本模型，不能把该结果当成真实外部模型连通性验证。

## 能力分类

能力目录来源于真实工具登记和运行注入条件。主分类是通用能力与平台专属能力；通用能力再按用途、搜索服务和插件来源分组。指令、自动处理权限、MCP 和 Skills 明确区别于直接注入模型的工具。

- QQ 群文件、成员和公告工具属于 NapCat 专属能力。私聊访问群和写公告仍需要相应权限。
- 群历史搜索是通用群聊工具，只在支持群聊的平台来源下使用。
- Telegram、微信没有已实现的专属模型工具时，显示“暂未提供”，不生成可装配开关。微信 iLink 当前仅支持私聊。
- 已装配只表示 Agent 配置包含该能力。实际调用仍取决于人格、发送者授权、运行态、资源范围、平台和插件状态。
- MCP 目录显示资源及运行时发现状态；页面不通过猜测生成工具名称。

## 中文文案准则

借鉴 [ASD-STE100 官方 FAQ](https://www.asd-ste100.org/STE_faq.html) 的短句、单一主题和主动表达原则，以及 [官方说明](https://www.asd-ste100.org/about_STE.html) 的术语一致性。中文界面不标称符合英文 STE 标准。

1. 一个句子说明一件事。指令以明确动作开始，例如“填写”“选择”“检查”“保存”。
2. 同一对象使用同一名称。区分“配置草稿”“发布配置”“格式检查”“连接状态”。
3. 字段帮助先解释用途，再给填写方法；只有影响操作时才补充生效时间。
4. 错误先说明失败位置，再给可执行的下一步。保留输入，不自动重放写请求。
5. 主界面直接显示费用、权限和中断影响。协议细节、估算方法和参数上限放入折叠帮助。

| 原表达 | 调整后的表达 |
| --- | --- |
| 修改后保存配置即可生效 | 修改先加入草稿。请保存运行配置后再使用。 |
| WebSocket URL invalid | WebSocket 地址格式错误。填写 ws:// 或 wss:// 开头的地址。 |
| 此内容已被其他操作更新，取得最新版本，对照并合并修改后再保存 | 此内容已被更新。当前输入已保留。请读取最新版本，合并修改后再保存。 |
| 检测成功 | 格式检查通过。发布配置后，读取连接状态。 |

## 验收边界

后端测试验证原子修订、草稿测试隔离和能力元数据。前端逻辑测试验证导航兼容、保存后保留其他草稿、权限分类和接入向导。浏览器操作使用独立临时数据服务；生产 NAS 仅通过运维接口核验，不绕过此前的浏览器 URL 限制。
