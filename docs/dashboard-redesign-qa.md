## 检查与修正记录

1. 初始能力页将大量通用工具平铺，平台能力出现太晚。改为类别切换与按用途/来源折叠分组，平台快捷入口保持可见。
2. 桌面对象选择器挤成两行。修正 flex 宽度，新增、启停和发布保持同一工作栏；手机再换行。
3. 单 Agent 保存被其他未完成表单阻止。只校验提交对象，保存后保留其他未完成草稿；补回归测试。
4. 当前 Agent 被远端删除时可能静默切换并丢失独立输入。未知 ID 显示空态；合并前阻止会移除脏对象的安装。
5. 测试面板因左侧长表单被拉高，发送按钮落到首屏之外。改为桌面粘性面板与有界结果区。最终按钮底部为 999.89px，视口高 1058px；手机保持顺序布局。
6. 原始 schema 错误难以修正。增加字段级中文定位和下一步，不回显提交值；错误提示与敏感值回归通过。

没有剩余的阻断性 P0/P1/P2 问题。P3：原有低频资源表单仍采用原工作区细节，可继续依据实际使用反馈调整密度。
